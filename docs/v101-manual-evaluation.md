# V1.0.1 人工实测清单

本次自动化测试使用模拟SDK，只验证软件流程。没有调用付费模型、上传真实学生作业或测得准确率提升。

## 样本与记录

使用获准处理的固定作业样本；记录样本编号、人工参考判断、审核模型标识、提示词版本、is_physics、完整grading_advice、结果图及人工检查结论。可以从30至50张代表性图片开始，但不据此宣称整体准确率。

| 样本 | 预期 |
| --- | --- |
| 清晰、全对 | 正确题打勾，不把等价写法判错 |
| 清晰、局部错误 | 圈出实际错误，附注内容与位置准确 |
| 清晰、多题、部分潦草 | 难辨认处问号和温和提示，其他可判断部分正常批改 |
| 模糊、反光（含局部） | 带重新上传前缀，前端要求重拍，没有生图调用 |
| 整图不可辨认 | false＋前缀，前端仍提示质量问题 |
| 清晰非物理题 | false且无前缀，提示非物理题，没有生图调用 |
| 小字、上下标、负号或小数点歧义 | 不依据正确答案猜学生原文，不能强行判错 |

## 区分误差来源

- 原文识别错误：学生写的符号被读错。
- 物理判断错误：原文读对但结论错误。
- 标注执行错误：建议正确但图片圈错、附注错误或原图被改写。
- 不确定性处理错误：该跳过却判错，或清楚内容被不必要跳过。

在相同样本上比较旧版与新版，分别统计正确作答误判率、真实错误识别率、可判断内容覆盖率和建议执行一致性。记录每项的分子/分母；图片数与小题数不可混用。不用大量跳过换取表面低误判率。

## 功能与部署手工检查

1. 密码错误留在登录页，任意或空用户名＋正确原密码可进入；刷新保留会话，退出后原图和API受保护。
2. 在实际HTTPS反代上验证登录、上传、下载、退出；设置Host透传和Secure Cookie，子路径使用末尾斜杠。
3. 质量拒绝点击重新上传选新图；技术失败点击重试，同一图不会因双击启动多次。
4. 小屏上检查清晰度提示、拒绝原因、图片放大与下载，确认批注不遮盖作答。
5. 部署前备份旧库，迁移重复执行安全；本次开发未直接启动现有业务库。

若实测判断正确而绘制仍频繁出错，应先归因于标注执行，再讨论后续程序叠加标注方案。本版不自动增加二次内容审核。
